# 김승태

코드잇에서 프론트엔드를 공부하고 있습니다.  
화면을 HTML로 만든 다음, 같은 판다마켓을 React 컴포넌트로 다시 만들고 있습니다.

## 판다마켓

[sprint-misson](https://github.com/stakim876/sprint-misson)

- 랜딩, 로그인, 회원가입, 상품 등록, 중고마켓, 상품 상세, 자유게시판을 HTML, CSS, JavaScript로 구성했습니다.
- React에서는 중고마켓 목록을 만들었습니다. 베스트 상품, 검색, 정렬, 페이지 이동이 됩니다.
- 상품 등록 폼은 입력값을 state에 저장하고, 자유게시판은 `/board` 주소로 연결했습니다.
